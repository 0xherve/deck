Module 01

Understand What You Have

Before you change anything, understand how it works. These three lessons walk the full path from a browser click to the filesystem and back.

Lesson 1.1

Read the server like a map

nodehono

Trace a request from the browser all the way to the filesystem. You'll open server/index.ts and follow how rootDir threads through every route.

What you'll do
  • Map every API endpoint and what it touches on disk
  • Understand the security middleware (origin guard, path traversal protection)
  • Follow the SSE file watcher and see how changes propagate
  • Explain back to Claude what happens when you save a file
Lesson 1.2

Read the client like a user

reacttanstack router

Follow a click from the sidebar file tree through the router into a component and back to an API call. No React jargon needed — just data flow.

What you'll do
  • Click a file in the sidebar and trace what code runs
  • Understand how tabs state works (useReducer + context)
  • See how the file viewer picks the right renderer (markdown vs code vs image)
  • Map the hooks: useFileContent, useFileMeta, useAutoSave
Lesson 1.3

Find and fix a real bug

debugging

Claude will point you to a bug in the codebase. You diagnose the root cause, write the fix, and verify it works. No hand-holding — you'll reason through it.

What you'll do
  • Reproduce the bug in the running app
  • Use browser devtools and server logs to narrow the cause
  • Write the smallest fix that addresses the root cause
  • Verify the fix and check for regressions
