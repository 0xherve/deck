Module 03

Git Integration

Build the source control experience that makes Deck feel like a real editor. You'll learn git internals along the way — not the commands, but how the data actually works.

Lesson 3.1

How git status actually works

gitinternals

Porcelain vs plumbing commands. The index (staging area) as a real data structure. The two-column status output decoded so your parser handles every case.

What you'll do
  • Run git status --porcelain and decode every possible XY combination
  • Fix the current status parser (it misses rename and copy states)
  • Understand the three trees: HEAD, index, working directory
  • Build a mental model of what "staged" actually means in git's object store
Lesson 3.2

Inline diffs that don't suck

gitui

Parse unified diff format. Build gutter markers (added/removed/modified lines) directly in the editor view, the way VS Code shows changes inline.

What you'll do
  • Parse the unified diff format (@@, +, -, context lines)
  • Map diff hunks to line numbers in the current file
  • Add colored gutter markers to the code viewer
  • Handle edge cases: new files, deleted files, binary files
Lesson 3.3

Branch operations

gitworkflow

Create, switch, and merge branches from the Deck UI. Handle the hard parts: dirty working directory, stash prompts, merge conflict detection.

What you'll do
  • Add API endpoints for branch list, create, switch, delete
  • Build a branch picker UI in the source control panel
  • Detect dirty state before switching and prompt to stash
  • Show merge conflicts when they happen (don't try to resolve them — just show them)
Lesson 3.4

Commit history and blame

gitui

Show commit log with a clean timeline. Add per-line blame annotations so you can see who wrote what and when. Learn git log formatting flags.

What you'll do
  • Build an API endpoint using git log --format with custom placeholders
  • Render a commit timeline in the source control panel
  • Add git blame --porcelain parsing for per-line annotations
  • Show blame in a subtle gutter overlay on the code viewer
