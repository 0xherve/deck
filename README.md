# StageOne

A local file browser and markdown editor.

## Features

- Browse your project files in a sidebar
- Read and edit markdown with a WYSIWYG editor
- View git diffs inline
- Auto-save with 5-second debounce

## Getting Started

```bash
bun install
bun run dev
```

### Architecture

The app uses **TipTap** for markdown editing, **Hono** for the backend, and **TanStack Router** for navigation.
